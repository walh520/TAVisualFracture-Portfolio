# 简单视觉碰撞：实现与证据

## 外部撞击惯性更新（GroundXY9）

- 外部 Box 通过注册组件路径、目标组件路径、Box 索引和几何键匹配前后采样。每次 Editor 更新按实际时间采样世界边界；停止时速度归零。首次注册、几何/缩放变化、无效时间间隔只建基线，普通移动/旋转不复原碎块。
- 优先使用进入侧，否则最近侧；前后世界矩形边界位移估算接触面速度，包括旋转造成的边界扩张。这不是精确旋转碰撞或 CCD。
- 每 Box/Chunk 每固定步最多一次速度响应：transfer × (1 + 双方较小恢复系数) × 相对接近速度。位置推出不作为速度来源。接触开始才允许一次弹起，保持接触不重复弹起，离开后重新允许。
- 新默认：外部撞击速度传递系数 1、弹起比例 0.15、弹起阈值 20 cm/s、地面摩擦衰减率 6/s。传递设为 0 保留原位置推出；弹起比例设为 0 只滑行；减小摩擦衰减率可延长滑行。
- 轻量模式每固定步只执行一次 exp(-衰减率 × 摩擦系数 × dt) 切向衰减，地形重采样不重复扣摩擦。起跳后不附加地面滚动；原重力、阻力和冲击角运动保留。严格模式摩擦不变，避让修正速度保留。
- 独立测试实际结果：PASS 4724 checks，包含既有 24/183 块回归、停止/基线/几何替换/移除、迭代不放大冲量、持续接触不重复弹起、空中无撞击、摩擦重采样、旋转边界速度及 30/60/120 FPS 外部轨迹。采样接触时刻允许有限位置误差（fixture 小于 4 cm）；不承诺不同编辑器采样率下完全相同轨迹。
- 核对 TVFSeeds.cpp、TVFFracture.cpp、TAVisualFractureBakeService.cpp SHA-256 与本轮前基线一致。没有修改 Bake 签名，不需要重烘焙。
- UE 参数映射自动化测试已补充但未运行。未运行 UBT/UHT、未重启 Editor；真实拖动手感、旋转 Box 视觉、反射和关卡性能待 UE 验收。

以下旧记录中 GroundXY8 和 4685 checks 为此前版本证据；外部仅位置推出的描述由本节更新。

本次不修改 Seed、Power 切割、碎块外观或 Bake 签名。不修改 Engine，不调用 UBT/UHT，不启动或重启 Editor。

## 当前默认：落地后 XY 避让（2026-09-18）

本节替代下方旧版默认单凸包/自碰撞说明。`bSimpleVisual=true` 现在显示为“落地后 XY 避让”。关闭该项才使用旧的完整碰撞路径。

- 不生成凸包、不做凸分解、不计算体积惯量；只读取既有 Chunk 的保守半径作为圆形 XY 占位。显示代理时画圆，外部 Box 显示简化世界包围盒。
- `MotionSystem` 保留原重力、解析阻力、旋转、Landscape 球体接触、摩擦和休眠。Bond 损伤、support、ApplyImpact 与源 Bake 不变。空中不运行碎块互撞或外部 Box 碰撞；因此空中可穿墙。
- 当前接触地面的活动碎块才进入二维空间网格。睡眠碎块保留占位，但睡眠对之间不求解；活动邻居推到它时唤醒。全部空中/睡眠时不构造邻居网格。
- 默认每主步 4 轮（可调，至少 1 轮，无原 4 轮上限），0 速度模式每轮完整修正当前接触对的穿透，没有明显重叠时提前结束。恢复“避让修正速度”：0（新实例默认）为立即分离；正值为 cm/s，每块每固定步累计纠正距离不超过 speed×dt。旧实例保存的值继续保留，可手动设为 0；与性能预算和真实速度无关。位置修正不注入速度、不产生扭矩，XY 相向速度做简单非弹性阻挡。
- 新增“碎块 XY 碰撞大小” `XYFootprintScale`，默认 1，UI 最小 0.05，底层要求有限正值。有效圆半径=保守半径×缩放，用于碎块互避及外部矩形横向间距；不改变地面高度、外部 Box、质量、冲击速度或滚动半径。缩小允许视觉网格相交。调试圆同步缩放，缓存版本为 GroundXY8。
- 新增“地面视觉滚动”默认开启，`GroundRollStrength=0.35`；0 关闭。接触地面的活动碎块按摩擦/阻挡后的真实切向速度绕 `normal×velocity` 翻滚，角速度=`strength×speed/originalRadius`。5 cm/s 以下停止，5–20 cm/s 用 smoothstep 渐入；空中、睡眠和纯位置修正不附加滚动。只叠加姿态，不写物理角速度，不增加地形查询。
- 不叠放：圆占位在 XY 摊开，允许拥挤处逐帧分离。圆半径采用保守外接半径，因此部分不规则碎块之间可能留缝，不保证单帧完全无重叠。
- 外部注册 Box 在当前会话缓存为世界 XY 矩形 + Z 高度区间。与落地碎块高度范围相交时沿最近 XY 边推出；不提供 Box 顶部支撑。正非均匀缩放通过既有八角点转换，源 Actor 仍排除。 外部签名单独追踪：移动/旋转/缩放、几何或注册变化只替换外部缓存，不 Reset 碎块、Bond 或事件历史。更新时检查并唤醒被新矩形覆盖的已落地睡眠块。无效配置暂时清空外部碰撞并提示，地面模拟继续；修复后自动恢复。旧严格模式仍保留静态外部物体合同。

- 轻量模式不再读取候选对、外部 Box 检查及接触点预算进行截断；这些预算只用于旧严格模式。原凸包顶点/表面误差/XPBD 子步设置也不作用于轻量模式。固定迭代次数是数值求解配置，不使用无限收敛循环；密集接触仍可能有少量残余重叠。

## 最短使用路径（UE 完整编译、重启之后）

1. 原有破碎对象继续使用已烘焙资产和 Landscape 快照，无需因为新增碰撞重新切割。
2. 在 `Visual Collision` 设置里开启 `Self Collision` 和／或 `External Box Collision`。旧组件默认均关闭。
3. 给外部 Actor 添加 `TAVisualFractureColliderComponent`，指定其 StaticMeshComponent。默认读取 Mesh 资源的 **Box** 简单碰撞，不读取凸体、三角复杂碰撞或整个 Mesh 包围盒。
4. 没有 Box 时，在 Static Mesh 资源中配置 Box，或开启注册组件的 `Use Manual Boxes` 并填写局部中心、旋转、半尺寸。
5. 点击“准备碰撞／冻结原位”。青色为碎块凸代理，黄色为外部 Box；用“显示／隐藏代理”切换覆盖线框。
6. 代理检查通过后点击“破碎”。Reset 销毁会话缓存，恢复原 Mesh。

注册物体在预览期间只能静止。几何、变换、启用状态、材质响应、过滤设置或注册集合变化时重置预览。源破碎 Actor 自身的注册整体碰撞不加入会话；未脱离碎块继续作为静态支撑，不改用户 UE 碰撞配置。

## 实现范围

### VisualProxy3：共面边界与整面法线

共面三角形合并后，用二维凸边界提取替代全体顶点的极角排序；剔除内部点、重复点及共线边采样，并压紧代理顶点索引。法线与面积改为累加整个多边形的有向面积向量，SAT、代理质量检查及厚度计算使用同一算法，不再假定前三个点非共线。真正零面积面仍拒绝。

独立核心测试结果：`PASS 1809 checks`，含有效共线开头多边形、四点接触、边界清理、输入顺序确定性及真实退化拒绝。UE 代理生成与截图资产仍未运行验证；Seed、TVFFracture 和 BakeService 文件修改前后 SHA-256 一致。本次不修改碎块烘焙或资产。

### VisualProxy2：渲染接缝与碰撞实体分离

准备代理不再以渲染三角面的 `IsClosed()` 为统一前置门禁。先从顶点直接构建闭合凸包，并通过已有体积、双向表面偏差、顶点预算和原位相邻侵入检查；只有需要凹体分解时才要求连接良好的闭合源网格，并尝试数值尺度的唯一边焊接。未通过质量检查的开放凹块仍明确拒绝，不直接填洞或使用整块 Box。

渲染接缝路径使用验证后的闭合单凸代理积分惯量，质量和质心仍沿用资产，并显示 `RenderSeamProxies` 数量。不改 Bake 资产或切割算法，重新准备碰撞即可使用新路径。新增 T 形接缝、微小坐标裂缝、真正缺少一面 Cube 的 Editor fixture；本次仅静态检查，未编译 UE、未运行这些 Editor fixture。

- Editor GeometryCore 直接消费现有 Chunk 表面；先从顶点生成单凸代理，仅凹体分解分支要求闭合连接。8 hull/Chunk、64 顶点/hull 是默认代理预算，不是碎块数量限制。
- 凸面合并为多边形，只有实际参与凸包三角形的顶点计入预算；源网格内部未使用顶点不计入 hull。
- 检查有向体积、凸性、流形边、双向表面采样偏差和冻结原位相邻代理穿透。Compound 内部面不作为可见外表去做误差检查；表面误差是采样估计，不是 Hausdorff 严格证明。
- 代理失败只阻止开启碰撞会话，不写回 Bake 资产。表面容差默认为 max(0.2 cm, Chunk 包围盒对角线的 1%)，体积误差为 5%。深度相邻侵入不通过屏蔽兄弟碰撞或缩球放行。
- 质量来自原 Chunk 体积与密度，完整局部惯量通过三角面体积分得到；新碰撞模式下冲击扭矩也使用该惯量。
- 外部 Box 的八个角经过局部 Box 旋转及 Mesh 世界变换，仅应用一次正缩放；静态世界凸体可以表达非均匀缩放后的盒形。
- 纯 C++ 接触模块使用确定性 swept-AABB 扫描、完整 SAT、面裁剪／支撑边最近点、每刚体对最多四个接触点。
- 接触每次位置迭代刷新。相同 Body/Feature 且锚点、法线兼容时传递当前子步的乘子；每个子步重新建立历史，不做跨子步 warm start。注册几何/设置变化重建场景，因此不复用旧版本历史。
- 默认 1/60 s 主步、4 子步、8 次位置迭代、2 次速度迭代。支持带旋转的 XPBD、速度重建、固定入射恢复目标、二维累计摩擦、睡眠与接触唤醒。
- 初始预稳定同步新旧姿态，不将修复位移变为发射速度。单次位置乘子的角度修正统一限幅，不分别限幅两个物体。
- Landscape 在凸代理顶点查询已有快照，不叠加旧球体接触。出界返回无地面；不支持高度场无法表达的墙体与悬挑。
- 自适应子步最多 8，包含平移、角扫掠和场加速度的估计；2026-09-18 起，超过子步能力仍继续运行，不因速度/厚度比暂停，也不截断输入速度。这不是 CCD，高速可能穿透薄物体。非有限数值和计算预算仍保留保护。
- 候选对、子形状对及地形查询工作量在每子步累积，接触点限制约束同时存在的流形容量。超过预算时整次主步不提交部分姿态。
- 临时代理保存在单个预览会话，不序列化、不标脏地图；缓存键包括资产签名、源几何 Hash、拓扑设置 Hash、正缩放、代理参数、物理预算及注册集合。
