# Release boundary / 发布边界

Included: plugin source, shaders, standalone tests, editor fixtures, bilingual design notes, dependency notes, attribution, and verification status.

Excluded: Unreal Engine source, generated build products, caches, project configuration, maps, meshes, materials, textures, audio, screenshots, videos, credentials, private tools, and machine-specific paths.

Included code is intended to make architecture, data flow, formulas, interfaces, failure paths, and validation reasoning reviewable. It is not a complete reusable production project.

本发布包含插件源码、Shader、独立测试、编辑器测试夹具、双语设计说明、依赖、署名和验证状态。

本发布排除 Unreal Engine 源码、构建产物、缓存、项目配置、地图、模型、材质、贴图、音频、截图、视频、密钥、私有工具和机器专用路径。公开代码用于审查架构、数据流、公式、接口、失败路径和验证思路，不构成可直接复用的完整生产工程。
